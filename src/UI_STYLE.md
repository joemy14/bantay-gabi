# Bantay Gabi UI Style

Use this style for all in-game UI.

- Colors: black panel (RGB 15,0,0), bright red accents (RGB 220,20,20), dark red shadow (RGB 110,0,0), white text.
- Corners: chunky rounded corners (about 12 to 16 px).
- Outlines: thick red UIStroke on panels (4), darker stroke on title banners (3).
- Text: Enum.Font.GothamBlack for headings and buttons, GothamMedium for descriptions. Use TextScaled.
- Buttons: a darker "lip" frame behind each button so it looks pressable.
- Motion: panels pop in with Back easing. Buttons squish on press and bounce back on release.
- Size: fit phones in landscape. Keep panels around 280 x 340 px or smaller.
- Theme: black and red, matching the game's mood.
